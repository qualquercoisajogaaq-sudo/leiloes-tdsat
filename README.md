# Leilões TDSAT

## Descrição do Projeto
O Leilões TDSAT é um sistema desktop desenvolvido em Java para controle e gerenciamento de produtos leiloados. O sistema permite cadastrar novos itens para leilão, listar os produtos disponíveis e acompanhar o status de venda de cada lote.

## Tecnologias Utilizadas
- Java SE (Desktop / Swing)
- MySQL (SGBD)
- JDBC (Java Database Connectivity)
- Git e GitHub (Controle de Versão)
